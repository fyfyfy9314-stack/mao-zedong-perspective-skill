# 毛泽东时间线与思想转折（1893—1976）

> 本文件由主 Agent 在时间线子任务超时后，依据已完成的著作研究、决策案例和官方年谱入口补齐。它用于定位思想变化，不把事件先后本身误写成因果。具体决策证据见 `05-decisions.md`，文本变化见 `01-writings.md`。

## 史料边界

- 核心编年依据为中央党史和文献研究院的[毛泽东年谱、传记与大事记入口](https://www.dswxyjy.org.cn/GB/427196/423773/428236/)。官方年谱以档案、会议记录、电报、批示和访问材料为基础，史实密度高；其政治评价仍需与原始文件及独立研究区分。
- 共产党员网的分期生平年表用于快速核日：[1893—1925](https://news.12371.cn/2013/12/20/ARTI1387526444616337.shtml)、[1926—1931](https://news.12371.cn/2013/12/20/ARTI1387527068354535.shtml)、[1932—1936](https://news.12371.cn/2013/12/20/ARTI1387527576633689.shtml)、[1941—1945](https://news.12371.cn/2013/12/20/ARTI1387527914993792.shtml)、[1969—1976](https://news.12371.cn/2013/12/20/ARTI1387529092274632.shtml)。
- 2023年修订九卷本《毛泽东年谱》覆盖1893—1976；其编纂价值与一手史料类型可见中央党史和文献研究院的[说明](https://www.dswxyjy.org.cn/n1/2026/0330/c427167-40691628.html)。

## 第一阶段：求索、调查与阶级分析（1893—1927）

| 时间 | 节点 | 对思维框架的意义 |
|---|---|---|
| 1893 | 生于湖南湘潭韶山 | 农村经验后来成为其理解中国社会结构的重要背景，但不能由出身直接推导政治结论。 |
| 1911—1918 | 参加新军、湖南第一师范求学、新民学会 | 从改良主义、民族主义和新文化思潮逐步转向组织化政治行动。 |
| 1918—1921 | 北京、上海与湖南活动；接触马克思主义；参与建党 | “思想—组织—行动”开始结合，单纯个人修养转向社会改造。 |
| 1925—1926 | 《中国社会各阶级的分析》；主持农民运动讲习所 | 把政治问题首先重写为“谁是敌人、谁是朋友”，形成对象分类与联盟分析。 |
| 1927 | 湖南五县调查、《湖南农民运动考察报告》；国共合作破裂 | 调查材料战胜组织内主流判断，农民被提升为革命中心力量；同年转向武装斗争。 |

**关键转折**：从知识分子式社会改造，转为以调查识别力量、以组织和武装改变力量对比。

## 第二阶段：弱者战略、根据地与领导权起伏（1927—1936）

| 时间 | 节点 | 对思维框架的意义 |
|---|---|---|
| 1927—1930 | 秋收起义、井冈山、红四军、古田会议；《红色政权为什么能够存在》《星星之火，可以燎原》 | 形成“避开强者主场—建立根据地—积累局部优势”的非对称竞争框架。 |
| 1930 | 《反对本本主义》 | 将调查确立为决策正当性的来源，反对把上级指示和书本原则机械化。 |
| 1931—1934 | 中央苏区建设，同时在党内军事领导上受排斥；第五次反“围剿”失败 | 个人经验路线与共产国际/中央的正规战路线冲突，为后来强调独立判断提供负面案例。 |
| 1934—1935 | 长征、遵义会议及机动指挥 | 在危机中重新获得军事领导影响；“事实结果—小范围复盘—调整指挥权”成为成功纠错范例。 |
| 1935—1936 | 到达陕北；瓦窑堡会议、西安事变前后统一战线形成 | 主要矛盾由国内阶级冲突重排为民族危机，联盟范围随之扩大。 |

**关键转折**：由根据地试验上升为全党战略；独立自主不再只是军事方法，也成为组织认知原则。

## 第三阶段：持久战、统一战线与延安整合（1937—1945）

| 时间 | 节点 | 对思维框架的意义 |
|---|---|---|
| 1937 | 《实践论》《矛盾论》 | 把调查—行动循环和矛盾分层理论化，为后续问题分类提供通用语言。 |
| 1938 | 《论持久战》；六届六中全会 | 在亡国论与速胜论之间构造阶段模型，把客观力量与主观能动性放进动态转化。 |
| 1939—1940 | 《共产党人》发刊词、《中国革命和中国共产党》《新民主主义论》 | 将统一战线、武装斗争、党的建设组合成总体战略，并提出新民主主义阶段。 |
| 1941—1942 | 调查研究决定、整风、《改造我们的学习》《反对党八股》 | 组织被视为知识生产系统：从实际中集中经验，通过批评和教育统一行动；同时整风也强化了思想与领导权集中。 |
| 1943—1945 | 中央领导地位制度化；七大与《论联合政府》 | 个人理论权威和组织权威高度结合；提出联合政府与较广泛社会联盟。 |

**关键张力**：实事求是与思想统一同时加强；前者需要异议，后者可能压缩异议。

## 第四阶段：从谈判与战争到全国执政（1945—1952）

| 时间 | 节点 | 对思维框架的意义 |
|---|---|---|
| 1945 | 重庆谈判 | 体现“可以谈判，但不解除自己的行动能力”；谈判与备战并行。 |
| 1946—1948 | 内战全面化；集中优势兵力、各个歼灭；辽沈等关键决策 | 将宏观力量统计转成战役关键点，在总体弱势下制造局部多数。 |
| 1949 | 七届二中全会、中华人民共和国成立 | 注意力从夺取政权转向执政、经济、组织纪律和“胜利后的腐化”风险。 |
| 1950—1953 | 土地改革、经济恢复、抗美援朝 | 在高不确定性中选择承担战争风险；安全边界、联盟信誉与长期威胁判断压过短期成本。 |

**关键转折**：以战争和动员见长的决策系统进入常态治理，原有方法的适用条件发生变化。

## 第五阶段：社会主义改造加速与矛盾重新分类（1953—1957）

| 时间 | 节点 | 对思维框架的意义 |
|---|---|---|
| 1953 | 过渡时期总路线 | 从原先较长期的新民主主义过渡设想，转向更快的社会主义改造。 |
| 1955—1956 | 农业合作化加速、工商业社会主义改造基本完成 | 大规模组织动员取得制度转换，但速度和反馈质量成为隐患。 |
| 1956 | 《论十大关系》；中共八大 | 尝试纠正照搬苏联模式，重新讨论中央/地方、重工业/农业等关系，表现出关系化、非单一最大化思维。 |
| 1957上半年 | 《关于正确处理人民内部矛盾的问题》、“双百”与整风 | 将社会冲突分为敌我矛盾和人民内部矛盾，主张后者以民主、说服和批评处理。 |
| 1957下半年 | 反右扩大化 | 批评者被重新分类为敌对力量，形成理论分类快速翻转并反过来压制信息的重大失败案例。 |

**关键张力**：分类是高效决策工具，但谁拥有重新分类的权力，决定了纠错机制是否真实存在。

## 第六阶段：大跃进、庐山与纠错机制破坏（1958—1965）

| 时间 | 节点 | 对思维框架的意义 |
|---|---|---|
| 1958 | 大跃进和人民公社化 | 群众动员、主观能动性和赶超目标压过资源、技术与统计约束；夸大信息在激励结构中上行。 |
| 1959 | 庐山会议由纠“左”转为批彭德怀 | 批评被敌我化，坏消息的政治成本上升，实事求是的反馈链断裂。 |
| 1959—1961 | 严重经济困难与大饥荒 | 构成人道与治理灾难；不同研究对死亡数量估计不一，但“千万级超额死亡”的量级不应被淡化，详见 `04-external-views.md` 与 `05-decisions.md`。 |
| 1962 | 七千人大会；毛承认中央责任并退居经济一线部分工作 | 出现纠错与责任承认，但没有放弃以阶级斗争解释政治风险的底层框架。 |
| 1962—1965 | 阶级斗争论重新强化、社会主义教育运动 | 对官僚化和修正主义的担忧上升，为发动更大规模政治运动铺路。 |

**关键转折**：早期“调查—试点—纠偏”的优势，被个人权威、指标竞争和敌我化批评共同侵蚀。

## 第七阶段：文化大革命、晚年外交现实主义与继承危机（1966—1976）

| 时间 | 节点 | 对思维框架的意义 |
|---|---|---|
| 1966 | 发动文化大革命 | 试图以群众运动打破官僚体系与既有权力结构，但缺乏程序边界、责任机制和事实校验，造成广泛迫害、社会失序和制度破坏。 |
| 1969 | 九大确认文革理论和林彪接班地位 | 运动理论制度化，同时个人权威达到高峰。官方年表也明确称九大批准了文革的错误理论和实践。 |
| 1971 | 林彪事件 | 接班设计失败，暴露高度个人化权力体系中的信息与继承风险。 |
| 1971—1972 | 乒乓外交、尼克松访华、中美关系破冰 | 面对中苏威胁重排主要矛盾，在强意识形态对立中实行外交现实主义；显示其框架仍可产生大幅策略转向。 |
| 1972—1974 | 中日邦交正常化、“三个世界”谈话 | 用全球力量分类重新解释联盟与威胁；分类具有生成力，也有过度简化风险。 |
| 1975—1976 | 批邓、继承安排反复；1976年9月9日逝世 | 晚年健康、派系与制度化不足叠加，继承问题未形成稳定规则。逝世时间见[人民网资料](https://cpc.people.com.cn/GB/33837/2534985.html)。 |

**关键张力**：国内治理继续依赖运动与敌我分类，外交却能根据力量变化作务实重排；两种表现来自同一“主要矛盾优先”方法，但反馈条件截然不同。

## 思想转折总表

1. **调查社会 → 重构革命主体（1927）**：从城市中心预设转向农村与农民。
2. **正面对抗 → 非对称根据地战略（1927—1930）**：避开强者设定的战场。
3. **国内革命优先 → 抗日民族统一战线（1935—1937）**：主要矛盾变化带动联盟变化。
4. **战争经验 → 通用认识论与组织方法（1937—1943）**：实践、矛盾、群众路线被理论化。
5. **较长新民主主义过渡 → 社会主义改造加速（1953—1956）**：阶段判断明显改变。
6. **人民内部矛盾民主处理 → 反右敌我化（1957）**：分类机制发生政治性翻转。
7. **调查与渐进试验 → 高指标群众动员（1958）**：经验主义约束被主观意志压倒。
8. **国内持续革命 → 外交力量均衡（1971—1972）**：对外政策出现高度现实主义调整。

## 对最终 Skill 的约束

- 不能只蒸馏革命战争时期的成功案例，再把方法无条件迁移到企业或常态治理。
- 每个“主要矛盾”判断必须带反证通道：谁能提供坏消息？分类错误如何被纠正？
- 群众动员必须转译为参与和反馈机制，不能复刻无程序边界的政治运动。
- 对1957、1958—1961、1966—1976的严重失败和人道后果必须作为模型失效条件，而不是脚注。
- 任何现代问题的回答都是基于公开历史材料的框架推演，不得伪造毛泽东对当代问题的原话或确定立场。
